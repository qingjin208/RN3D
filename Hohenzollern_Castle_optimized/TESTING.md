## 🎯 预期效果

### ✅ 正确的表现：
- 模型被从指定角度切割
- 切割面显示为**不透明的红色平面**
- 可以清楚看到切割的边界
- 旋转模型时截面始终正确显示

### ❌ 错误的表现（如果还有问题）：
- 模型没有被切割 → 检查 `localClippingEnabled`
- 切割后是空心的 → 检查截面是否正确渲染
- 控制台有错误 → 查看错误信息

## 🔍 调试技巧

### 查看控制台输出

打开浏览器开发者工具（F12），你应该看到：

```
🔪 切割参数: { cutDepth: 50, cutAngle: 0, ... }
✂️ 裁剪平面: { normal: [...], constant: ... }
🎨 材质更新: { clippingPlanesCount: 1, ... }
```

### 常见问题排查

#### 问题 1: 模型没有变化
**原因**: Canvas 未启用裁剪
**解决**: 确保 `<Canvas gl={{ localClippingEnabled: true }}>`

#### 问题 2: 截面不可见
**原因**: `showCutPlane` 为 false
**解决**: 勾选"显示切割面"复选框

#### 问题 3: 截面颜色不对
**原因**: 材质配置问题
**解决**: 检查 `capColor` 参数

## 🎨 自定义设置

### 修改截面颜色

在 `CutCakeApp.tsx` 中：

```tsx
<CutModelWithCap 
  capColor="#00ff00"  // 改为绿色
  // 或其他颜色
/>
```

### 隐藏截面

取消勾选"显示切割面"复选框，或：

```tsx
<CutModelWithCap showCutPlane={false} />
```

## 📊 性能监控

查看帧率：
- 60 FPS = 优秀
- 30-60 FPS = 良好
- < 30 FPS = 需要优化

如果性能不佳：
1. 降低像素比 `dpr={[1, 1]}`
2. 关闭阴影 `shadows={false}`
3. 简化模型
