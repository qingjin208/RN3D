已将切割截面材质改为**不透明的实心平面**，移除了复杂的 Stencil Buffer 设置。

## 🔍 调试技巧

### 如果封口不可见

1. **检查控制台**
   ```
   查找错误信息或警告
   ```

2. **验证 Canvas 配置**
   ```tsx
   <Canvas gl={{ localClippingEnabled: true }}>
   ```

3. **检查材质属性**
   ```tsx
   console.log('Cap Material:', {
     transparent: material.transparent,  // 应该是 false
     side: material.side,                // 应该是 DoubleSide (2)
     depthWrite: material.depthWrite     // 应该是 true
   })
   ```

4. **临时增强可见性**
   ```tsx
   // 临时改为亮绿色，更容易看到
   const capMaterial = new THREE.MeshStandardMaterial({
     color: '#00ff00',  // 亮绿色
     emissive: '#00ff00', // 自发光
     emissiveIntensity: 0.5,
   })
   ```

### 如果封口位置不对

1. **打印平面参数**
   ```tsx
   console.log('Clipping Plane:', {
     normal: clippingPlane.normal,
     constant: clippingPlane.constant
   })
   ```

2. **可视化平面位置**
   ```tsx
   // 添加一个辅助线框
   <mesh geometry={capGeometry}>
     <meshBasicMaterial 
       color="#ffffff" 
       wireframe={true}
       transparent={true}
       opacity={0.5}
     />
   </mesh>
   ```
