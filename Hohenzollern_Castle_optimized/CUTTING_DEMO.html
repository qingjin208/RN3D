🍰 3D 模型切割功能技术说明

📋 核心原理

使用 Three.js 的 Clipping Planes（裁剪平面）技术实现实时切割效果

1 用户输入参数
  • 切割深度：0-100%
  • 切割角度：0-360°
2 计算裁剪平面
法向量 = (cos(角度), 0, sin(角度))
平面位置 = (深度 / 100) × 模型大小 - 模型大小 / 2
3 应用到材质
material.clippingPlanes = [plane]
material.clipShadows = true
4 渲染结果

GPU 在片段着色器中自动裁剪掉平面一侧的像素

🔧 代码实现流程

// 1️⃣ 根据角度和深度计算裁剪平面 const clippingPlanes = useMemo(() => { const angleRad = (cutAngle * Math.PI) / 180 const normal = new THREE.Vector3( Math.cos(angleRad), // X 分量 0, // Y 分量（水平切割） Math.sin(angleRad) // Z 分量 ) const modelSize = 10 const constant = (cutDepth / 100) * modelSize - modelSize / 2 return [new THREE.Plane(normal, constant)] }, [cutDepth, cutAngle]) // 2️⃣ 将裁剪平面应用到材质 <mesh geometry={nodes.HZ3.geometry} material={materials.HZ3_Material_u1_v1} > {/* 附加裁剪平面 */} <primitive object={clippingPlanes[0]} attach="clippingPlanes-0" /> </mesh> // 3️⃣ 可视化切割面（可选） {showCutPlane && ( <mesh geometry={cutPlaneGeometry} material={cutPlaneMaterial} /> )}

⚖️ 技术方案对比

✅ Clipping Planes（推荐）

优点

  • 性能优秀，GPU 加速
  • 实时响应，无延迟
  • 支持动态调整
  • 可显示切割截面
  • 内存占用低

缺点

  • 仅视觉裁剪
  • 不修改原始几何体
  • 无法导出切割后模型

❌ CSG 布尔运算

优点

  • 真实修改几何体
  • 可以导出结果
  • 物理上准确的切割

缺点

  • 性能差，CPU 密集
  • 复杂模型很慢
  • 不适合实时交互
  • 可能产生拓扑错误

🎯 关键配置

// ⚠️ 必须启用本地裁剪！ <Canvas gl={{ localClippingEnabled: true // ← 这行至关重要 }} > <CutCakeModel cutDepth={50} cutAngle={45} /> </Canvas>

如果不设置 localClippingEnabled: true，裁剪平面将不会生效！

📐 数学原理图解

                    切割平面
                       |
                       |
          _____________|_____________
         /             |             \
        /              |              \
       /     保留部分   |   裁剪部分     \
      |                |                 |
      |                | ← 平面位置      |
      |                |                 |
       \               |               /
        \              |              /
         \_____________|_____________/
                       |
                  法向量方向 →
平面方程：Ax + By + Cz + D = 0
其中 (A,B,C) 是法向量，D 是平面到原点的距离

🚀 性能优化建议

移动端优化
  • 降低像素比：dpr={[1, 1.5]}
  • 关闭阴影：shadows={false}
  • 简化切割面几何体
  • 模型大小控制在 20MB 以内
  • 使用 Draco 压缩
代码优化
  • 使用 useMemo 缓存计算结果
  • 克隆材质避免影响其他实例
  • 条件渲染不必要的元素
  • 预加载模型：useGLTF.preload()
