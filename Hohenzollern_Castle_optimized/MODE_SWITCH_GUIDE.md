# 🎯 切割模式切换功能说明

## 📋 功能概述

现在程序支持**两种切割模式**的实时切换：

### 1️⃣ **Cut Face（切割面模式）** - 默认模式
- **显示内容**：只显示横截面（精确匹配模型边界）
- **视觉效果**：在切割位置显示一个红色的实心平面，精确贴合模型的截面轮廓
- **特点**：
  - ✅ 截面完全匹配模型的实际形状
  - ✅ 不会出现超出的大矩形
  - ✅ 从任何角度都能看到精确的切割边界
  - ✅ 适合观察内部结构

### 2️⃣ **Cut Body（切割体模式）**
- **显示内容**：显示被切掉的部分（用红色实体填充）
- **视觉效果**：被切除的那部分模型会变成红色实体显示
- **特点**：
  - ✅ 直观看到被移除的部分
  - ✅ 可以对比切割前后的差异
  - ✅ 适合理解切割范围

## 🎮 使用方法

### 界面控件

控制面板现在有这些按钮和滑块：

```
┌─────────────────────────────────────────────────────┐
│ Silo消耗                                             │
│                                                      │
│ Cut Depth: [30%] ████████░░░░░░ (滑块)              │
│ Cut Angle: [0°]  ████████████████ (滑块)            │
│                                                      │
│ Depth (%) [输入框]  Angle (°) [输入框]               │
│                                                      │
│ Mode: [Cut Face] [Cut Body]  ← 新增的模式切换按钮    │
│                                                      │
│ ☑ Show the cutting surface                          │
│                                                      │
│ [Reset]                                              │
└─────────────────────────────────────────────────────┘
```

### 操作步骤

1. **选择模式**：
   - 点击 **"Cut Face"** 按钮 → 显示精确的切割截面
   - 点击 **"Cut Body"** 按钮 → 显示被切掉的红色实体

2. **调整切割参数**：
   - 拖动 **Cut Depth** 滑块（0-100%）：控制切割深度
   - 拖动 **Cut Angle** 滑块（0-360°）：控制切割角度

3. **或直接输入数值**：
   - 在 Depth (%) 输入框中输入具体数值
   - 在 Angle (°) 输入框中输入具体角度

4. **查看效果**：
   - 鼠标左键拖动：旋转模型
   - 鼠标滚轮：缩放
   - 鼠标右键拖动：平移

5. **其他控制**：
   - ☑ **Show the cutting surface**：勾选/取消显示切割面
   - **Reset** 按钮：重置所有参数（深度=0，角度=0）

## 🔍 技术实现

### Cut Face 模式原理

```typescript
// 1. 主模型应用裁剪（保留一侧）
material.clippingPlanes = [clippingPlane]

// 2. 复制模型几何体，应用反向裁剪（显示截面）
const reversePlane = new THREE.Plane(
  clippingPlane.normal.clone().negate(),
  -clippingPlane.constant
)

// 3. 使用相同的几何体，但只显示截面部分
<mesh geometry={modelGeometry} material={capMaterial}>
  // capMaterial 应用了反向裁剪平面
</mesh>
```

**关键**：使用模型本身的几何体 + 反向裁剪，确保截面精确匹配模型边界。

### Cut Body 模式原理

```typescript
// 1. 主模型应用裁剪（保留一侧）
mainMaterial.clippingPlanes = [clippingPlane]

// 2. 复制模型，应用反向裁剪（显示被切掉的部分）
reverseMaterial.clippingPlanes = [reversePlane]
reverseMaterial.color = '#ff6b6b'  // 红色

// 3. 两个模型叠加显示
<mesh geometry={geometry} material={mainMaterial} />     // 保留部分
<mesh geometry={geometry} material={reverseMaterial} />  // 切掉部分（红色）
```

## 🎨 自定义设置

### 修改切割面颜色

在 `CutCakeApp.tsx` 中修改 `capColor` 参数：

```tsx
<DualModeCutModel 
  cutDepth={cutDepth}
  cutAngle={cutAngle}
  showCutPlane={showCutPlane}
  mode={mode}
  capColor="#00ff00"  // 改为绿色
/>
```

常用颜色：
- `#ff6b6b` - 红色（默认）
- `#4CAF50` - 绿色
- `#2196F3` - 蓝色
- `#FF9800` - 橙色
- `#9C27B0` - 紫色

## 🐛 常见问题

### Q1: 切换模式后没有变化？
**A**: 确保：
- 切割深度 > 0% 且 < 100%
- "Show the cutting surface" 已勾选
- 刷新页面重试

### Q2: 切割面看不到？
**A**: 
- 检查深度是否设置为 0% 或 100%（这两种情况不显示截面）
- 旋转模型从不同角度观察
- 确认 "Show the cutting surface" 已勾选

### Q3: 切割面太大或超出模型？
**A**: 这是之前的问题，现在已经修复。如果还出现：
- 刷新页面
- 检查控制台是否有错误信息

### Q4: 性能卡顿？
**A**:
- 关闭阴影：`shadows={false}`
- 降低像素比：`dpr={[1, 1]}`
- 减少模型复杂度
